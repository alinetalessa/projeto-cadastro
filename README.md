# Cadastro de Pessoas

Sistema web para cadastrar, consultar, editar e excluir registros de pessoas.

O projeto foi desenvolvido utilizando HTML, CSS, JavaScript e Node.js com Express.



## Como executar o projeto

### 1. Instalar as dependências

Entre na pasta server:

```bash
cd server
```

Instale as dependências:

```bash
npm install
```

### 2. Iniciar o servidor

Ainda dentro da pasta server, execute:

```bash
node index.js
```

### 3. Acessar o sistema

Abra o navegador e acesse:

http://localhost:3000



## Funcionalidades

- Cadastrar pessoas.
- Listar pessoas cadastradas.
- Editar registros existentes.
- Excluir registros.
- Validar os dados informados.
- Impedir cadastros duplicados.
- Armazenar os registros em arquivo JSON.
- Manter os dados após atualizar a página.
